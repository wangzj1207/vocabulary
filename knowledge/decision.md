# 待決策事項

## 字庫原始資料的再散布條件

- **狀態**：待確認，暫不阻塞遊戲功能迭代。
- **現況**：目前字庫整理自 `mahavivo/english-wordlists` 的「台灣高中英文參考詞彙表.txt」。上游 README 說明該檔下載自校方網站，但 GitHub repository 未提供可辨識的 LICENSE 檔（GitHub license API 回應 404）。公開可下載不等於已授權再散布。
- **風險**：本專案 repository 是公開的，提交完整詞義資料會繼續散布上游詞表與中文釋義；大考中心現行參考詞彙表亦註明非營利使用與轉載註明出處的條件，但不能據此推定現有第三方整理檔的中文釋義權利。
- **推薦**：後續公開發佈前，將字庫遷移至有明確授權的來源；官方詞表可用於標註英文詞條與級別，中文釋義則使用已確認可再散布的授權資料，並保留逐筆來源欄位。若希望沿用目前整份中譯字表，先向權利人取得明確授權。
- **官方來源補充**：大考中心[111 學年度起適用詞表 PDF](https://www.ceec.edu.tw/files/file_pool/1/0K213635079130230766/%E9%AB%98%E4%B8%AD%E8%8B%B1%E6%96%87%E5%8F%83%E8%80%83%E8%A9%9E%E5%BD%99%E8%A1%A8%28111%E5%AD%B8%E5%B9%B4%E5%BA%A6%E8%B5%B7%E9%81%A9%E7%94%A8%29.pdf) 說明詞表著作權屬大考中心基金會，僅供非營利使用且轉載需註明出處；營利使用需事前書面授權。上游 [`mahavivo/english-wordlists` README](https://github.com/mahavivo/english-wordlists) 表示中譯整理檔下載自校方網站，並非直接提供該中譯內容的授權聲明。因此官方詞表條件不能直接延伸到目前中譯整理檔。
- **本次採用方式**：本專案定位為免費教育用途；依官方 PDF 的非營利與註明出處條件，已加入匹配詞條的 CEEC 級別及官方詞性對照，並在 README／遊戲介面標註來源。未匹配詞條保持未分類，未使用官方資料替換既有中文釋義。
- **本機比對結果**：官方 PDF 抽取 5,990 個列項、展開替代拼法後 6,104 個 headword；分級筆數為 992／998／1,000／1,002／1,001／997。現有 5,624 詞條中 4,570 筆匹配、1,054 筆未匹配；另外有 1,534 個官方 headword 未在現有字庫，728 筆詞性不同。完整官方詞表及逐筆比對明細僅供本機分析，未加入 repository；暫存檔已清理。
- **可繼續的工作**：遊戲互動、題目流程、版面、學習紀錄、資料驗證工具等不依賴這份詞義資料授權的實作。

## 網站部署目標與 CD

- **狀態**：已決定採用 GitHub Pages；使用者於 2026-11-27 明確要求「用 GitHub Action 配合 GitHub Pages 發布」。
- **發布網址**：<https://wangzj1207.github.io/vocabulary/>。
- **部署方式**：GitHub Actions 僅在 main push 且 CI 通過後發布；Pull Request 只執行測試。artifact 限定遊戲執行所需檔案，不打包知識文件、測試或工具。
- **後續驗收**：第一次 workflow 執行後檢查 Pages deploy job，並確認公開首頁與所需 JS 資源可載入；若 repository Pages 尚未啟用，需在 GitHub Settings → Pages 將 Source 設為 GitHub Actions。
- **詞庫注意事項**：公開部署會提供目前詞庫下載；原始整理檔的中譯再散布授權仍待權利確認，相關推薦與風險見本文件「字庫原始資料的再散布條件」。
