# 英文單字學習遊戲：願景與路線圖

## 願景

做一款面向台灣高中生、能用輕鬆遊戲方式持續累積英文單字的網頁遊戲。題目以台灣學測與高中英文參考詞彙為核心，提供繁體中文釋義、發音和即時回饋，讓玩家可以每天短時間練習，逐步擴大詞彙量並追蹤學習進度。

長期希望字庫達到約 7,000 個有可靠來源的單字。字量與詞義都應以可核對的詞表或辭典資料為基礎；不以重複詞或未確認的翻譯填數。

## 目前狀態

- 已有可在瀏覽器開啟的單頁遊戲原型：`index.html`。
- 字庫載入自 `vocabulary.js`，目前包含 **5,519 個去重詞條**，有英文單字、詞性、繁體中文釋義及來源標記欄位。
- 每輪隨機出 10 題英文選中文選擇題；作答後顯示正解與釋義。
- 可使用瀏覽器的英文語音合成播放單字發音。
- 已練習的單字以 `localStorage` 保存在目前裝置與瀏覽器。
- 目前「單字本」與「學習紀錄」導覽按鈕只有提示訊息，尚未有獨立頁面或完整功能。
- 字庫目前尚未達到 7,000；現行大考中心《高中英文參考詞彙表》為六級、約 6,000 詞條。學測詞彙以常用 4,500 字詞為主，並可能出現第六級以上詞彙。因此「7000 單」應視為擴充目標，不應直接標示成現行學測官方必考範圍。
- 目前接入的是公開的台灣高中參考詞彙整理檔，尚未逐筆與大考中心現行詞表校對，也尚未完成來源授權與詞義品質審查。

## 路線圖

### 已完成

- [x] 建立繁體中文的單字遊戲首頁與基本視覺介面。
- [x] 建立英文單字選中文意思的四選一答題流程。
- [x] 加入答對／答錯回饋、下一題、跳過題目及 10 題一輪的流程。
- [x] 加入瀏覽器語音合成發音。
- [x] 加入答對題數、連對紀錄與本輪進度顯示。
- [x] 將遊戲資料由少量示範題改為外部字庫檔 `vocabulary.js`。
- [x] 將已練習詞條存入瀏覽器本機儲存空間。
- [x] 整理目前已知的字量差異：現有 5,519 詞條，尚未達 7,000；現行大考中心字表約 6,000 詞條。

### 待完成

- [ ] **確認正式詞表範圍**：以大考中心現行《高中英文參考詞彙表》為主要依據，保留級別，區分學測核心範圍與進階擴充詞。
- [ ] **校對現有字庫**：與正式詞表比對，檢查拼字、重複詞、詞性、中文釋義及漏字；記錄每筆資料的來源。
- [ ] **擴充至約 7,000 詞條**：優先收錄台灣高中／升學考試相關詞彙；若現行官方表不足 7,000，清楚標示額外詞條的來源與級別，不宣稱全部都是官方學測範圍。
- [ ] **確認資料使用條件**：為詞表及中文釋義記錄來源與授權，確保遊戲用途符合條款。
- [ ] **改善詞義選項品質**：避免使用不相關或容易產生歧義的中文釋義作為干擾選項；可依詞性、級別或主題挑選選項。
- [ ] **加入學習模式**：提供依詞表級別、熟悉度或主題選擇練習範圍的入口。
- [ ] **完善複習進度**：區分新字、答對、答錯及待複習詞條，讓玩家能針對不熟單字重練。
- [ ] **完成「單字本」功能**：可搜尋單字、查看中文釋義、詞性與學習狀態。
- [ ] **完成「學習紀錄」功能**：顯示累計學習量、答題表現及近期進度。
- [ ] **檢查手機版與桌面版操作**：確認題目、較長釋義、語音按鈕與導覽在不同螢幕尺寸下都易用。
- [ ] **補上資料與操作驗收**：確認字庫筆數、詞條格式、隨機出題、答題回饋、本機進度保存及重新開啟後的狀態。
